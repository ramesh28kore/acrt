# ACRT source release — 11 October 2026

This release publishes the pending ACRT implementation from the existing
development repository. It includes authentication and identity reconciliation,
academic access helpers, learning content, coding practice and playground,
quizzes, the content importer and image assets, test series, and curriculum
scheduling with administration previews and spreadsheet/document exports.

## Verified locally

- Application suite: 171 tests passed; nine Docker execution integration tests
  skipped because Docker Desktop's Linux engine was unavailable.
- Strict TypeScript checking: passed.
- ESLint: no errors; six existing component Fast Refresh warnings.
- Production build: passed.
- M08 migration: 15 isolated in-memory database checks passed, including
  unauthorized access, stale previews, and preservation of student activity.
- Dependency audit: no vulnerabilities in 587 locked packages after compatible
  patches and replacement of the obsolete transitive esbuild version.

Earlier audit evidence is retained as a dated baseline, not as the current
release's check results. These checks do not constitute a complete production
security audit of every pending module.

## Publishing targets

- Existing repository: https://github.com/ramesh28kore/acrt (main).
- Confirmed live site: https://pixel-perfect-replica-4849.lovable.app.
- Sign-in page: /auth.
- Signed-out access to /dashboard redirects to /auth?redirect=%2Fdashboard.

The live routes above were verified in a browser against the currently
published site before this source release; they do not prove that this release
has been deployed.

Lovable's Pixel Perfect Replica project is currently disconnected from Git.
Its Git settings say connecting creates a new repository and importing an
existing repository is unsupported. Pushing to acrt therefore does not update
this site. The Lovable draft also contains independent homepage and deployment
diagnostics work that must be preserved during reconciliation. Do not force
push or replace the published history of either repository.

## Backend prerequisites

The reconciled code and supabase/migrations depend on the intended portal
schema, rather than only the historical four-table Drizzle scaffold. Verify
the hosted backend schema, migration history, and server environment before
publishing this release to Lovable. No hosted database migration or data write
was performed as part of this source release. The scheduling migration was
tested only in an isolated database.

## Packaging

The committed Bun lockfile is authoritative. Local environment files,
credentials, Python bytecode, importer plans/private material, and the generated
package-lock.json are excluded from publication.
